---
title: "角色：将助手图片移到用户消息"
description: 将助手图片移到下一条用户消息。
---

## 作用

此变换将每张助手图片移到下一条用户消息之前。如果后面没有用户消息，则将图片追加到末尾。图片的角色改为 user，图片来源和图片顺序保持不变。其他内容保持不变。

## 使用场景

当上游接受助手图片字段，但忽略其中的图片内容时，启用此变换。

## 参考

| 属性 | 值 |
| --- | --- |
| Type ID | `role_assistant_image_to_user` |
| 阶段 | `request` |
| 作用域 | Provider, Global, API key |

## 配置

此变换没有选项。使用空的 `config` 对象。

```json
{
  "transform": "role_assistant_image_to_user",
  "enabled": true,
  "phase": "request",
  "models": ["*"],
  "config": {}
}
```
