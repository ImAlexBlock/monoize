---
title: "ロール：アシスタント画像をユーザー側へ移動"
description: アシスタント画像を次のユーザーメッセージへ移動します。
---

## 動作

各アシスタント画像を、次のユーザーメッセージの直前へ移動します。後続のユーザーメッセージがない場合は、末尾に追加します。画像のロールを user に変更し、画像ソースと画像の順序を保持します。他の内容は変更しません。

## 使用する場面

上流がアシスタント画像のフィールドを受け付けても画像の内容を無視する場合に、この変換を有効にします。

## リファレンス

| 項目 | 値 |
| --- | --- |
| Type ID | `role_assistant_image_to_user` |
| フェーズ | `request` |
| スコープ | Provider, Global, API key |

## 設定

この変換にオプションはありません。空の `config` オブジェクトを使用します。

```json
{
  "transform": "role_assistant_image_to_user",
  "enabled": true,
  "phase": "request",
  "models": ["*"],
  "config": {}
}
```
