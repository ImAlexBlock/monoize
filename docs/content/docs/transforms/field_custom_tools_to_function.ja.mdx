---
title: "フィールド: カスタムツールを function に変換"
description: 選択した custom ツールを JSON function に変換し、custom 非対応の上流で使用します。応答では変換した呼び出しを元に戻します。
---

## 使用する条件

上流が `type: custom` を拒否し、JSON `function` ツールを受け付ける場合に有効にしてください。
たとえば、クライアントの自由形式の `apply_patch` ツールを上流が受け付ける関数に変換できます。
Channel のプロトコル設定を上流のエンドポイントに合わせてください。
この変換はツール定義を変更します。選択したプロトコルや URL は変更しません。

同じモデルフィルターと設定で、`request` と `response` のルールを 1 件ずつ追加してください。
応答ルールは、現在の上流への試行で実際に変換したツールだけを元に戻します。
応答ルールだけを有効にしても、通常の関数呼び出しは変換されません。

## 動作

リクエストルールは、選択した custom ツールを JSON function に変換します。`namespace.tools` 内のツールも対象です。
元の custom 入力文字列を、必須の文字列フィールド `input` で包みます。
元の文字列が JSON を含む場合も、その文字列全体を保持します。
対応するツール履歴、関連する結果、`tool_choice` も更新します。`allowed_tools` 内の選択も対象です。

応答ルールは変換した呼び出しを元に戻し、`input` の文字列を取り出します。
完全な引数が JSON 文字列の場合は、その文字列をデコードします。
各変換は namespace とツール名で識別します。
`names` に `"*"` を指定しても、通常の function ツールはそのままです。
function と変換対象の custom ツールが同じ namespace と名前を持つ場合、転送前にリクエストを拒否します。
上流が namespace を省略した場合、Monoize は名前からリクエスト内のツールを一意に識別できる場合だけ namespace を復元します。

変換後の関数は custom の文法制約を保持しません。Lark の制約も対象外です。
選択したツールが文字列引数を受け付ける場合だけ使用してください。

### ストリーミング

変換した呼び出しの引数は、呼び出しが完了するまでバッファに保持します。
その後、Monoize は custom 入力の文字列全体を送信します。
JSON のエスケープシーケンスやラッパーが複数の断片に分かれていても、custom 入力の断片には出力しません。
テキストと推論内容は通常どおりストリーミングされます。
上流の開始イベントにツール名がある場合、通常の関数引数も通常どおりストリーミングされます。
開始イベントに名前がなく、リクエストに一致する変換記録がある場合、Monoize はツールまたは応答の完了まで、そのツールのイベントを保留します。
その後、変換した呼び出しを元に戻します。通常の関数の場合は、保留したイベントを元のまま再送します。
この処理では使用量データとメタデータを保持します。
ストリームでエラーが発生した場合、未完了の引数を破棄します。

### apply_patch の形式

変換した `apply_patch` 呼び出しでは、応答ルールが完成したパッチの文字列を整形します。

- パッチのマーカーを `*** Begin Patch` と `*** End Patch` に統一します。
- `*** End of File` マーカーと外側の `<invoke>` ラッパーを除去します。
- Add File の接頭辞がない内容行に `+` を付けます。すでに `+`、`-`、`\` で始まる行は保持します。
- `@@` ヘッダーや別のパッチ区間で Add File の接頭辞付与を止めます。Update File の削除行は保持します。
- Update File のハンクにコンテキスト行がなく、削除内容と追加内容が同一の場合、そのハンクを除去します。

リクエストのスキーマには、`apply_patch` に限ってこれらのパッチ指示を追加します。
他のツールには汎用の文字列入力スキーマを使用します。

## リファレンス

| 項目 | 値 |
| --- | --- |
| タイプ ID | `field_custom_tools_to_function` |
| フェーズ | `request`、`response` |
| スコープ | Provider、Global、API key |

## 設定

| オプション | 型 | 必須 | デフォルト | 説明 |
| --- | --- | --- | --- | --- |
| `names` | string[] | いいえ | `["apply_patch"]` | custom ツール名を完全一致で選択します。空配列は変換を無効にします。`"*"` はすべての custom ツールを選択します。空文字列は指定できません。 |

### ルールの例

`target-model` を変換が必要なモデル名に置き換えてください。
以下の 2 件のルールを一緒に使用してください。

```json
[
  {
    "transform": "field_custom_tools_to_function",
    "enabled": true,
    "phase": "request",
    "models": ["target-model"],
    "config": { "names": ["apply_patch"] }
  },
  {
    "transform": "field_custom_tools_to_function",
    "enabled": true,
    "phase": "response",
    "models": ["target-model"],
    "config": { "names": ["apply_patch"] }
  }
]
```

すべての custom ツールを変換するには、両方のルールに `"names": ["*"]` を指定してください。
この設定でも通常の function ツールは変換されません。
