---
title: "欄位：自訂工具轉函式"
description: 將指定的 custom 工具轉換為 JSON function，供不支援 custom 的上游使用。在回應中還原已轉換的呼叫。
---

## 何時使用

當上游拒絕 `type: custom`，但支援 JSON `function` 工具時，啟用此轉換。
例如，將用戶端的自由文字 `apply_patch` 工具轉成該上游支援的函式。
請確認 Channel 的協定設定與上游端點一致。
此轉換修改工具定義，不會改變所選協定或 URL。

使用相同的模型篩選條件與設定，新增兩條規則：一條 `request`，一條 `response`。
回應規則只會還原目前上游嘗試中實際轉換的工具。
單獨啟用回應規則不會轉換一般函式呼叫。

## 行為

請求規則會將指定的 custom 工具轉換為 JSON function，包括 `namespace.tools` 內的工具。
原始 custom 輸入字串會包裝在必填字串欄位 `input` 中。
即使原始字串包含 JSON，也會完整保留。
規則也會更新對應的工具歷史、關聯結果與 `tool_choice`，包括 `allowed_tools` 內的選擇器。
轉換後的歷史呼叫與結果會省略選填的項目 `id`，因為 custom 項目 ID 不能用於 function 項目。
用於關聯呼叫與結果的 `call_id` 維持不變。

回應規則會還原已轉換的呼叫，並解開其 `input` 字串。
如果完整參數是 JSON 字串，則解碼該字串。
每次轉換都以 namespace 與工具名稱識別。
一般 function 工具維持不變，即使 `names` 內包含 `"*"`。
如果 function 與待轉換 custom 工具的 namespace 和名稱都相同，請求會在轉送前遭到拒絕。
如果上游省略 namespace，Monoize 只會在工具名稱能唯一識別請求內的工具時還原 namespace。

轉換後的函式不保留 custom 語法限制，包括 Lark 限制。
請只在指定工具可以接受字串參數時使用此轉換。

### 串流回應

已轉換呼叫的參數會暫存到該呼叫完成。
Monoize 隨後傳送完整的 custom 輸入字串。
JSON 跳脫序列與包裝物件即使分散在多個片段中，也不會出現在 custom 輸入片段內。
文字與推理內容會繼續正常串流傳輸。
如果上游在開始事件中提供工具名稱，一般函式參數也會正常串流傳輸。
如果開始事件沒有工具名稱，且請求中存在符合條件的轉換紀錄，Monoize 會將該工具的事件延後至工具或回應完成。
接著，Monoize 會還原已轉換的呼叫，或依原樣重播一般函式的暫存事件。
此處理會保留用量資料與中繼資料。
串流發生錯誤時，尚未完成的參數暫存會被捨棄。

### apply_patch 格式

對於已轉換的 `apply_patch` 呼叫，回應規則會整理完整的補丁文字：

- 將補丁標記統一為 `*** Begin Patch` 與 `*** End Patch`。
- 移除 `*** End of File` 標記與外層 `<invoke>` 包裝。
- 在 Add File 中沒有前綴的內容行加上 `+`。保留已以 `+`、`-` 或 `\` 開頭的行。
- 遇到 `@@` 標頭或其他補丁區段時，停止新增 Add File 前綴。保留 Update File 的刪除行。
- 如果 Update File hunk 沒有上下文行，且刪除內容與新增內容完全相同，則移除該 hunk。

請求 schema 只會為 `apply_patch` 加入這些補丁說明。
其他工具使用通用的字串輸入 schema。

## 參考

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `field_custom_tools_to_function` |
| 階段 | `request`、`response` |
| 作用域 | Provider、Global、API key |

## 設定

| 選項 | 類型 | 必填 | 預設 | 說明 |
| --- | --- | --- | --- | --- |
| `names` | string[] | 否 | `["apply_patch"]` | 依名稱精確比對 custom 工具。空陣列會停用轉換。`"*"` 選取全部 custom 工具。不接受空字串。 |

### 範例規則

將 `target-model` 換成需要轉換的模型。
請搭配使用以下兩條規則。

```json
[
  {
    "transform": "field_custom_tools_to_function",
    "enabled": true,
    "phase": "request",
    "models": ["target-model"],
    "config": { "names": ["apply_patch"] }
  },
  {
    "transform": "field_custom_tools_to_function",
    "enabled": true,
    "phase": "response",
    "models": ["target-model"],
    "config": { "names": ["apply_patch"] }
  }
]
```

若要轉換全部 custom 工具，請在兩條規則中都設定 `"names": ["*"]`。
此設定不會轉換一般 function 工具。
