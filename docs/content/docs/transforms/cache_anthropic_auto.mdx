---
title: "Auto-cache: Anthropic request"
description: Enable top-level automatic caching for Anthropic Messages requests.
---

The request-level cache setting uses one of four cache slots. Each explicit node breakpoint uses one slot. At four slots, these transforms add no marker.

## What it does

This transform adds `cache_control` to the request JSON. The upstream moves the cache point to the last eligible content block as the conversation grows. Client-supplied `cache_control` values remain unchanged.

## Reference

| Property | Value |
| --- | --- |
| Type ID | `cache_anthropic_auto` |
| Phase | `request` |
| Scopes | Provider, API key |

## When to use

Use it when a Channel accepts Anthropic automatic caching. Keep `cache_anthropic_system` enabled for the stable system prefix. Confirm that any relay accepts the top-level field.

## Configuration

| Option | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `ttl` | string | No | `"5m"` | `5m` or `1h`. Cache lifetime of the inserted breakpoint. `5m` sends `{"type": "ephemeral"}`. `1h` adds `"ttl": "1h"`. |

Check the selected Provider pricing before you enable `1h`. Cache write charges use the configured billing Profile.

Anthropic rejects a request when a `1h` breakpoint follows a `5m` breakpoint. Use the same `ttl` in all Anthropic `cache_*` rules, or use `1h` only on earlier breakpoints. Anthropic also rejects a request when the last block has an explicit `cache_control` with a different TTL.

Provider rules run before API key rules. A later rule changes a Monoize marker only while its target remains unchanged. API key rules override Provider rules for that target. Monoize never changes a `cache_control` that the client sent. Run transforms that edit or reorder nodes before cache rules. Changed targets lose their saved ownership. Identical nodes also lose ownership because their identity is ambiguous.

```json
{
  "transform": "cache_anthropic_auto",
  "enabled": true,
  "phase": "request",
  "models": ["claude-*"],
  "config": { "ttl": "1h" }
}
```
