---
title: "Auto-cache: Anthropic tool results"
description: Insert a cache_control breakpoint on the final tool result.
---

The request-level cache setting uses one of four cache slots. Each explicit node breakpoint uses one slot. At four slots, these transforms add no marker.

## What it does

When the request submits tool results, this transform inserts an Anthropic ephemeral `cache_control` breakpoint on the final tool result. The cache point moves forward with each tool-result submission.

Requests without tool results pass through unchanged.

## Reference

| Property | Value |
| --- | --- |
| Type ID | `cache_anthropic_tool_use` |
| Phase | `request` |
| Scopes | Provider, API key |

## When to use

- Agent clients run long tool loops against an Anthropic-compatible upstream.
- You want each loop iteration to re-read the conversation prefix from cache instead of paying full input price.

## Configuration

| Option | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `ttl` | string | No | `"5m"` | `5m` or `1h`. Cache lifetime of the inserted breakpoint. `5m` sends `{"type": "ephemeral"}`. `1h` adds `"ttl": "1h"`. |

Check the selected Provider pricing before you enable `1h`. Cache write charges use the configured billing Profile.

Anthropic rejects a request when a `1h` breakpoint follows a `5m` breakpoint. Use the same `ttl` in all Anthropic `cache_*` rules, or use `1h` only on earlier breakpoints.

Provider rules run before API key rules. A later rule changes a Monoize marker only while its target remains unchanged. API key rules override Provider rules for that target. Monoize never changes a `cache_control` that the client sent. Run transforms that edit or reorder nodes before cache rules. Changed targets lose their saved ownership. Identical nodes also lose ownership because their identity is ambiguous.

### Example rule

```json
{
  "transform": "cache_anthropic_tool_use",
  "enabled": true,
  "phase": "request",
  "models": [
    "claude-*"
  ],
  "config": { "ttl": "1h" }
}
```
