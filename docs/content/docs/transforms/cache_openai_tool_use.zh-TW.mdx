## 行為

此變換在符合條件的工具結果內容區塊上插入顯式的 OpenAI 提示詞快取斷點。它針對支援顯式快取斷點的 GPT 模型系列。

沒有符合條件的工具結果區塊的請求原樣通過。

## 不支援斷點的上游

部分中轉站以同一個 GPT 模型名稱對接不同後端，其中有的後端會拒絕斷點欄位。此類上游回傳 HTTP 400，錯誤訊息為 `prompt_cache_breakpoint is not supported on this model`。

Monoize 會自動處理這種拒絕：

1. 從請求本文中移除所有 `prompt_cache_breakpoint` 欄位。
2. 向同一上游重送一次請求。用戶端看不到第一次失敗。
3. 記住該上游的 base URL 與模型，有效期一小時。一小時內首次送出前即移除該欄位。

此紀錄僅保存在單一行程的記憶體中，重新啟動後清空。如需永久解決，請在對應的 Provider 上停用此變換。

## 參考資訊

| 屬性 | 值 |
| --- | --- |
| 類型 ID | `cache_openai_tool_use` |
| 階段 | `request` |
| 範圍 | Provider, 全域, API 金鑰 |

## 適用場景

- 智慧代理用戶端在支援顯式斷點的 OpenAI 相容上游上執行工具迴圈。
- 你希望工具迴圈的前綴在迭代之間保持快取。

## 設定

此變換沒有設定項。`config` 使用空物件。

### 範例規則

```json
{
  "transform": "cache_openai_tool_use",
  "enabled": true,
  "phase": "request",
  "models": [
    "gpt-*"
  ],
  "config": {}
}
```
