## 論理モデル

クライアントは論理モデル名でリクエストします。Monoize はその名前を Provider と Channel に解決します。クライアントが見る名前は、上流ベンダーの名前と一致する必要はありません。

1 つの論理モデルは、複数の Provider が持つ各 Channel に対応付けられます。クライアントを変更せずにフェイルオーバーを実現できます。

![モデルデータベース](/images/en/models.webp)

## リダイレクト

Channel のモデルエントリでは、`redirect` に実際の上流モデル名を設定できます。

例：クライアントは `my-fast-model` を呼び出します。1 つの Provider は `gpt-4o-mini` に、別の Provider は `claude-3-5-haiku-20241022` にリダイレクトします。課金とログは常に論理名を表示します。

`admin` または `super_admin` アカウントでは、上流レスポンスのモデル名が異なる場合、リクエストログの論理モデルバッジの横に表示されます。
モデルバッジまたは Channel にポインターを合わせて、**実際のモデル**を確認してください。この値は課金を変更しません。
[リクエストログ](/ja/docs/request-logs)を参照してください。

## モデルメタデータと価格

**モデルデータベース**ページはモデルメタデータと Billing Profile レートを保存します。Monoize は [Models.dev](https://models.dev) からメタデータと価格候補を取り込みます。

課金の計算：

1. モデル対応付けの有効な Billing Profile を選択します。
2. 上流モデルまたは論理モデルの完全なレート行列を選択します。
3. モデル倍率の上書き、または Provider 倍率を適用します。

各レートレコードは価格と価格通貨を保持します。手動で入力したレートの既定の価格単位は `CNY / 1M tokens` です。Models.dev から取り込んだレートは `USD` を保持します。

価格エディターには `CNY`/`USD` の通貨セレクターがあります。入力した数値は選択した通貨でそのまま解釈され、為替換算は行われません。Models.dev から取り込んだレートは `USD` を保持します。

エディターは各用量クラス(キャッシュ書き込み 5m / 1h を含む)ごとにオフピーク価格と任意のピーク価格を設定します。ピーク価格は北京時間の月曜から金曜、`09:00–12:00` と `14:00–18:00` にのみ適用します。ピーク欄を空にすると、常にオフピーク価格で課金します。

Monoize は現在の CNY/USD 為替スナップショットで `CNY` 価格を換算し、料金をナノドル単位で各ユーザーの台帳に積算します。モデルが `CNY` 価格を使い、利用できる為替スナップショットがない場合、そのモデルへのリクエストは `model_pricing_required` を返します。推定レートでの課金は行いません。

## モデル一覧

`GET /v1/models` は、呼び出し元 API キーが利用できる論理モデルを返します。結果はキーのモデル制限とグループ所属を反映します。

## モデルグロブ

変換ルールと一部の制限は、モデルグロブパターンに対応します。

- `*` は空を含む任意の文字列にマッチします。
- `?` はちょうど 1 文字にマッチします。
- マッチングは大文字小文字を区別し、モデル名全体に固定されます。

例：`gpt-4*` は `gpt-4o` と `gpt-4o-mini` にマッチします。`o4-mini` にはマッチしません。


## 課金プロファイルの管理

ツールバーの **プロファイル管理** を開きます。各プロファイルにモデル数とレート数が表示されます。

- **複製** は全レート行を新しいプロファイル名に複製します。
- **削除** はプロファイルと全レート行を削除します。一致ルールまたは Provider から参照されているプロファイルは削除できず、理由がインライン表示されます。

## 価格の同期

ツールバーの **同期** を開き、**models.dev を同期** または **カタログを同期** を選択します。同期が完了すると、更新・削除されたモデル数と、手動価格を保持したモデルの一覧がレポートに表示されます。手動価格が同期で上書きされることはありません。


## モデル価格を直接追加する

ツールバーの **価格を追加** を開き、モデル名を入力して、右パネルで各価格欄を入力します。モデルにレジストリのメタデータは不要で、プロファイルは単一チャネルに紐づきません。このプロファイル経由でこのモデルをルーティングするすべての Provider がこの価格で課金します。


## アカウントクラスをまたぐプロファイル共有

課金プロファイルは特定のアカウントクラス専用ではありません。任意の Provider が任意のプロファイル名を参照できます。価格の分離は維持されます。各リクエストは自分のクラスの Provider のプロファイルだけを解決するため、共有プロファイルは両クラスに同じ価格を適用するだけです。クラスごとに異なる価格が必要な場合はプロファイルを複製してください。

## モデル制限

価格エディターの**モデル制限**カードで、コンテキストウィンドウとトークン上限(最大入力・出力・合計)を設定します。空欄は無制限です。メタデータがない場合も保存時に作成され、新しい価格と一緒に設定できます。
